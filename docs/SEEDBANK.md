# Seed bank — the contiguous seed archive

A seed bank packs many tiny seeds into one immutable object: a 32-byte
header, a jump table sorted by digest (32 + 4 + 4 per entry), and a
16-aligned payload arena. A lookup is O(log n); a slice is O(1) pointer
arithmetic — one CID to pin instead of a DHT storm of provider records.

## The format (kernel/src/seedbank/seedbank.h)

```
0   magic "ZXSB"
4   version u8 = 1
5   count     u32      jump-table entries
9   table_off u32      jump table start
13  payload_off u32    payload arena start
17  bank_len  u32      total length
21  11 bytes reserved
32  jump table: count x 40 bytes, sorted by digest:
      digest[32]  sha256 of the seed's bytes
      off     u32  payload offset
      len     u32  payload length
... payload arena: seeds back-to-back, 16-aligned
```

## The kernel surface

- `sb_open` / `sb_find` / `sb_count` — the archive primitives,
  freestanding on aarch64 and i386 (no libc, no 64-bit division helpers).
- `sb_catalog` — the master catalog over the hosted banks: a digest
  resolves to its bank and its exact slice.
- `POST /bank` — the door endpoint: `[digest 32]` →
  `[status][bank u16][len u32][offset u32]` (+ the seed bytes when they
  fit the reply budget).
- The compiled-in blob (`zxv_seedbank_blob.h`, generated by
  `tools/seedbank/mk_blob.py`): the inaugural bank registers at boot —
  `[BANK_OK] compiled-in seed bank: 560 seeds, 58071808 bytes`.

## The inaugural bank

560 seeds: the 407 ZXVG app icons + the boot font + the 152 ASCW-Golden
fonts. One CID (`bafybeib23pkydq6iwyfbe4nxygaiocxtyahi4hxqozyqxcz5avp23y44yy`),
public on Filebase, hosted by every fleet node.

## The tooling

- `tools/seedbank/mk_seedbank.py` — pack (digest, bytes) pairs into a
  bank, exactly the kernel's layout.
- `tools/seedbank/mk_blob.py` — a bank as a compiled-in C header.

## The economy

The seeds are the compressed forms: parametric ZXVG vectors, fonts,
fabrication manifests. The AI-social logs distill to premium seed files,
payable only in VINO floating vouchers on the DRAGON / PHOENIX /
THUNDERBIRD rails — the network's effective capacity is the seeds, not
the raw payloads.
