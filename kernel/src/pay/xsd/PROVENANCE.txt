ISO 20022 XSD provenance for kernel/src/pay (fetched 2026-10-09)

www.iso20022.org (the publisher) was refused by this environment's egress
proxy (HTTP 403 on CONNECT), and github.com / codeload.github.com were also
refused. The schemas below were therefore taken from open-source packages
that redistribute the unmodified ISO 20022 base schemas (each file carries
the "Generated by Standards Editor ... ISO 20022 version : 2013" header that
the ISO 20022 Registration Authority's generator writes). Every file was
cross-checked against at least one independent copy where one was found.
These are the BASE ISO 20022 message schemas; they are NOT the SWIFT CBPR+
usage-guideline schemas (those are distributed through SWIFT MyStandards to
registered users and were not obtainable). CBPR+ restrictions are therefore
enforced in C by pay_iso.c and are documented there.

Version notes:
  - pain.002: CBPR+ uses pain.002.001.10. No copy of .10 was obtainable, so
    pain.002.001.11 (the next base version) is used. The generator emits
    the 001.11 namespace.
  - head.001.001.02 is the BAH version CBPR+ uses.
