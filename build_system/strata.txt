# One line per directory or file under kernel/src: "<path> <stratum>". The
# longest match wins, so a file can be pinned apart from its directory; a path
# without an extension pins its .c and .h together. Checked by
# build_system/verify_strata.py, which build_system/verify_layers.sh runs: an
# unmapped source or header, a line that matches nothing, an include of a
# higher stratum, or an unprovided REQUIRES fails the check.
#
# Placement is by role, then by measurement: where a module's includes reach a
# higher stratum than its role, it sits at the stratum its includes force and
# the note says why. Nothing was moved or renamed to make the check pass.
