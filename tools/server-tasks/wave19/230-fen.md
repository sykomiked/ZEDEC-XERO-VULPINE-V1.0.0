# Wave 19 task: Fen (slot 230), Plants and specimens
Read ../APP_WAVE_SPEC.md first. This is an L2 app: manifest says `layer L2` and composes its built_from apps' blocks with `use`; it may only start after those L1 waves are merged.
Depends on: wave 2 (071 gleaner), wave 7 (058 pinhole), wave 8 (093 understory), wave 9 (102 fieldguide).
Manifest: `slot 230`, `layer L2`, `version 1.0.0` and its `provides` lines (so L3 apps can use it, C1), `icon icons/l2/230-fen.svg`, `budget 233`, model `apps/fen_model.{h,c}`, blocks under kernel/src/apps/blocks/fen/, one `use <id> 1` per part below. The composed logic lines must fit ZXAPP_LOGIC_MAX (128) and the uses ZXAPP_USES (8); if either fails, stop and report it; do not raise a limit or edit the part.
What it does: Identifies plants from photos, logs specimens and builds a local flora dataset: photos and the register in the Hoard (`files.read`, `files.write`, `search.query`), the place only after `place.ask` (`place.here`), an identification suggestion from `swarm.ask` (held), the dataset published locally (`aipi.put`, `web4.cid`).
Uses: `use fieldguide 1` ("show a caution" and match ranking); `use pinhole 1` ("photo fits" and device ready); `use gleaner 1` (train and test split and label counts); `use understory 1` (land entries for the site). Call these composed entries; do not re-implement them; each part's manifest is itself the block (C1).
Logic (new decisions only; a critical one has two or three `logic` lines for one `provides`, so the witness holds it as BOTH when they disagree):
- (critical) "may share this specimen's location" (species not on the protected list) in Ada as Eve + MUMPS as MYRA witnessed (MYRA looks the species up in the protected index)
- growth measures (height mm over dates, growth per day exact) in FORTRAN as Trebago
- protected-species limits (no location, no collection advice) in Ada as Eve
- trait matrix (specimens x traits, match counts per species) in APL as KRON
- specimen register (register numbers, counts, refusing on overflow) in COBOL as Sutra
- taxonomy tree in MUMPS as MYRA
Paraconsistent (BOTH test, in test_zxapp.c): expert A identifies species X and expert B species Y, giving BOTH; the test asserts state 3 and that both names stay on the specimen until evidence resolves it. Join the sources with `lpres_conjoin` / `lpres_disjoin` in C; never re-derive the tables.
Safety: Never says a plant or fungus is safe to eat; a protected species' location is never published.
Integers only: no float or double anywhere; a division that is not whole uses kernel/src/rational in C.
needs: fs.read, fs.write, search, location, camera, ai.ask, net.
Planned (no runtime yet): Natural, MATLAB, Bourne shell.
