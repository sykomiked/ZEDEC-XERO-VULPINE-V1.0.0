# The sovereign bearer accounts

The Crown, the Ministry, and the keyless third rail — the 11% tributes.

## The accounts

Generated by `mk_bearer.c` on the kernel's own post-quantum crypto
(ML-DSA-87 lattice identities — the design's "lattice-derived equivalent"
of EVM keys), with the private material sealed by the kernel's
AES-256-GCM under a key derived from the bearer's passphrase:

- `crown.{address,pub,sealed}` + `crown.card-{dragon,phoenix,thunderbird}.{address,pub,sealed}`
- `ministry.{address,pub,sealed}` + the three card rails
- `third-fountain.address` — the R&D fountain: no key exists; the
  address is a protocol constant (`sha256("zxv/tribute/third-fountain/v1")`),
  so its balance can only be spent by the scheduled grant program.

The cards are Iridium Black Swan tier (the six-tier matrix's apex).

## The tributes (the protocol wiring)

Each of the three rails takes 11% of protocol yield:

- **Crown (11%)** — held by default in V-bills unless the bearer withdraws.
- **Ministry (11%)** — the same, funding public utility.
- **The third fountain (11%)** — the R&D rail: funds the olive-oil-barrel
  grants, which vest over a fixed number of cycles (each grant pays a
  scheduled slice every N cycles until its balance is delivered — wired
  to pay automatically, never stuck in limbo).

## Verify

```
cc -I kernel/include -I kernel/src/robin_debanks -I kernel/src/modbind \
   -I kernel/src/e8 -I kernel/src/event_space -I kernel/src/surplus \
   verify_bearer.c kernel/src/robin_debanks/aes256_gcm.c \
   kernel/src/robin_debanks/sha256.c -o verify_bearer
./verify_bearer ~/.zxv/bearer/crown.sealed "$CROWN_PASS" crown
./verify_bearer ~/.zxv/bearer/crown.card-dragon.sealed "$CROWN_PASS" dragon dragon
```

All eight sealed secrets round-trip (accounts: AAD = the bearer's name;
cards: AAD = the rail, the rail also in the key derivation).
