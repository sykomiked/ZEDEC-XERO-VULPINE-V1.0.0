# ASCW Golden

ZXV's UI and system font. ASCW Golden Latin II is the primary face; each
other file is the Golden member for one script, plus five ASCW sibling faces
where Golden has none. Licence: SIL Open Font License 1.1 (`OFL.txt`),
notices per face in `FONTLOG.md`. `fontmap.json` is the generated script and
locale map. How the system uses them: `docs/FONTS.md`.
