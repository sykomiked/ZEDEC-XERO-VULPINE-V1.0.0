01What it is

ZXV is a complete operating system written from scratch in freestanding C: its own kernel, file system, network stack, cryptography, interface, applications, languages, and a swarm of small AI models that run locally on an integer-only engine — Tiamat, the system's own agency. Nothing in it requires a cloud service to work.

It is meant to be one platform a person can hold entire. The same source boots in this browser tab, on a bare disc, in a virtual machine, and links into another program as a library.

02Why it may interest you

  • Runs where you already are. A browser tab, a bootable disc, a qcow2 for a VM or VPS, or libzxv with SDKs for twelve languages.
  • Works without a cloud. The AI swarm, the ledger and the files are local; the network is something it joins, not something it needs.
  • Deterministic. Integer-only arithmetic in the kernel — the same input yields the same bits on every CPU.
  • Post-quantum from the start. ML-KEM, ML-DSA and SLH-DSA, checked against NIST vectors.
  • Paraconsistent. Contradictions are tagged and routed through four-valued logic; they never silently decide, and never crash a decision.
  • An exact economy. A ledger that balances to the unit every cycle; contribution is metered and verified, never asserted.
  • Open and verifiable. Apache-2.0 source; this release is content addressed, so what you fetch is what was sealed, by hash.

03Where it honestly stands

We would rather be believed than impressive.

  • Boots in QEMU on x86-64 and ARM64. It has not yet run on physical hardware.
  • The desktop build runs a real local model end to end; the bare-metal side is earlier, and shows it.
  • A catalogue of applications is layered and building out in waves; what is here works, what is not here does not pretend to.
  • Every claim carries a test: make -C kernel verify-all runs the gate, and build_system/verify_boot.sh rebuilds the disc and boots it under emulation, yourself.

05Get the source

The whole repository rides inside this content root as a git bundle. Clone it straight over IPFS, on any machine:

ipfs get -o zxv.bundle /ipfs/ROOT_CID/09_source/zxv.bundle
git clone zxv.bundle

or through the gateway you are reading this on:

curl -O https://GATEWAY/ipfs/ROOT_CID/09_source/zxv.bundle
git clone zxv.bundle

or from the mirror:

git clone https://github.com/sykomiked/ZEDEC-XERO-VULPINE-V1.0.0

Then prove the boot yourself (Docker is the only dependency):

bash build_system/verify_boot.sh
