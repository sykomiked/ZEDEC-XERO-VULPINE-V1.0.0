Build it yourself

The whole source rides inside this content root as a git bundle — clone it straight over IPFS, on any machine:

ipfs get -o zxv.bundle /ipfs/ROOT/09_source/zxv.bundle
git clone zxv.bundle

or through this gateway:

curl -O GATEWAY/09_source/zxv.bundle
git clone zxv.bundle

The manifest MANIFEST.tsv names every file, its CID and its SHA-256.
