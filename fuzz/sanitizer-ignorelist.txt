# Clang sanitizer ignorelist (-fsanitize-ignorelist=) for the fuzzers and the
# CI sanitizer jobs. Every entry is a place where the flagged behaviour is
# INTENDED, with the reason. Nothing here hides a bug in ledger, parser or
# economy code: those files are never listed.

# Vendored orlp/ed25519 (ref10 field arithmetic, kept byte-for-byte close to
# upstream): carries are propagated with left shifts of negative limbs
# (`h0 -= carry0 << 26`), which C calls undefined but every supported
# compiler implements as the arithmetic shift ref10 relies on.
[shift-base]
